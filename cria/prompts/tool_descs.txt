# Descriptions the model reads for cria's synthetic tools. Format: `<tool> = <description>` (one per
# line). Schemas live in writeproxy.py (the file/web tools it advertises) and loop.py (task_complete,
# advertised on coder turns); only the model-facing description is tunable here.
write_file = Create or completely overwrite a file with its full content.
read_file = Read a file's contents (read-only). Optionally pass a 1-based inclusive line range with start_line/end_line.
list_dir = List the entries of a directory (read-only). Defaults to the current directory.
grep = Search file contents with a Python regular expression. path defaults to the current directory; include is an optional relative filename glob. Generated directories and discovered symbolic links are skipped and listed; set include_generated=true or explicitly name a generated directory to search it. Errors are reported, not treated as no matches.
glob = Find files by relative glob pattern, with ** matching any number of directories. path defaults to the current directory. Generated directories and discovered symbolic links are skipped and listed; set include_generated=true or explicitly name a generated directory to search it. Errors are reported, not treated as no matches.
edit_file = Replace one exact snippet in an existing file. old_string must match exactly once; set new_string to "" to delete.
web_fetch = Fetch a web page (read-only) as text. Large pages are saved under {{SPILL_DIR}}/; the returned path and file say whether the full page or only part was saved. Grep the file, use find="<keyword>" to select a section (separate searches with |; missing searches are named), or use cursor="<token>" to page through the reduced view. Do not repeat an unchanged fetch to see more. Use raw=true for literal source, including HTML markup; find also works with raw, but cursor does not. Fetch uses a browser User-Agent; code you write must set its own headers when needed.
web_search = Search the web for pages. Each result is a title, URL, and short description; results may come back inline or be saved to a {{SPILL_DIR}} file for you to grep. Pair with web_fetch to open a specific result in full.
task_complete = Signal completion of the assigned step or task only after it is done and confirmed. Pass `summary`: a short plain-text description of what you did.
