# The note a harness-owned compaction reply carries when the model-written summary was NOT delivered
# (parsed by prompts.load_map). It names the check that refused the summary; what follows it is derived
# from the recorded tool calls, not written by a model. The reason lines are closed: one per check.
header = Briefing withheld: {{LENS}}. The model-written summary of the earlier turns was not delivered because {{REASON}}. Nothing below is a model's account; it is derived from the recorded tool calls and the workspace.
reason_retrospective = it described what to do next rather than what happened
reason_files = it named a file as present that the workspace survey does not list
reason_changes = it said a file was created or edited that no recorded call could have changed
reason_sizes = it stated a file size the workspace survey contradicts
reason_build = it said the build or tests passed when no recorded run could back that
reason_figures = it stated a figure that appears in none of the recorded evidence
reason_unavailable = the check that reads such a summary could not be run
reason_none = no usable summary was produced (an empty, cut-off or tool-call answer, even after one retry)
reads = Files read in the earlier turns (a result was recorded for each): {{FILES}}
