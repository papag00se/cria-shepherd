# Which write calls the completion checks could not account for (probegate.unsettled_text). Parsed by prompts.load_map.
lead = ⟦ctx:checks⟧ the checks above do not cover every write you sent: the harness returned no result for {{PATHS}}, and the write is not established.
unknown = Its program left no completion record when the checks finished and nothing shows whether it ever started (it may still be running, may have been interrupted, or may never have started).
running = Its program was still running when the checks finished, so the write may still land.
dead = Its process is gone: it was killed or ended before it left a completion record, so the file may hold none, part or all of what was sent, and this write will not land by itself.
overlapped = Its program finished only while the checks were running, so the checks may have read the file before it changed.
tail = Read the file to see what it holds now before you finish; if it is not what you intended, write it again.
