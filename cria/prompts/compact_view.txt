# Post-compaction view strings (selfcompact). write_stub replaces a write-tool call's big argument
# body in turns OLDER than the last tool call — the content is durably ON DISK and in the files
# list; read_file is the road back (operator's design, run 0728-m14: the compacted view carries
# what exists, not the bytes, so one file's content stops appearing six times in one prompt).
# Parsed by prompts.load_map.
write_stub = [elided {{CHARS}} chars — this exact content is on disk at {{PATH}}; read_file to view it]
# The stub above is only true of a write that LANDED. Stamped on a REFUSED edit it asserts content
# is on disk that never got there — walked on mellum2 1786196176 call 0182, where the claim fed the
# steer author's "the side_effect fix landed" hallucination (0144), which the coder believed for
# ~30 calls. The refused form keeps the elision and drops the claim.
write_stub_refused = [elided {{CHARS}} chars — this write was REFUSED (see the tool result below); the content never reached disk]

# A write that LANDED and was then SUPERSEDED by a later write to the same path. Its content is not
# what is on disk, so it may not carry write_stub's claim. `last_write` was one index across the
# whole span, so every older write got the on-disk wording whatever path it touched: one real prompt
# carried six of them for a single Ruby file at four different byte counts, and at most one could be
# true (#5b).
write_stub_superseded = [elided {{CHARS}} chars — an EARLIER version of {{PATH}}, replaced by a later write in this session; read_file for what is actually on disk now]
# THE OTHER HALF OF AN EDIT. The key lists carried `new_string` and not `old_string`, so a
# historical edit reached its reader as the BEFORE text in full and the AFTER text as a
# pointer — every seat asked to judge whether the coder is looping was shown no diff, which is
# exactly the judgement it was convened to make (walked on shipping-rates-rb x ternary-bonsai
# 1787111689). Both halves are equally historical; both get a pointer. Worded separately
# because a replaced fragment is not "an earlier version of the file" — it is a piece of one.
write_stub_replaced = [elided {{CHARS}} chars — the text this edit replaced in {{PATH}}; read_file for what is actually on disk now]
