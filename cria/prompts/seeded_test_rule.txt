This governs the tests that were already in the repository when you started — they describe behaviour someone else depends on. A test YOU wrote earlier in this session is yours: if its own setup or fixture is wrong, correct the test. The ONE exception is a test that asserts something about an EXTERNAL system — a live service's response, a remote count, a third-party format — which you have since observed to be different. Quote the command you ran this session and the output it returned, then correct the test to match what came back. The test's own failure message is not that evidence, and a test about this project's own behaviour never qualifies. Weakening or deleting an assertion for any other reason is not a fix.
