Your edit_file call has an EMPTY `old_string`, so it names no text in the file — an empty string is not a place in the file, and it would match every position equally. Nothing was changed and the file on disk is untouched. edit_file replaces one exact piece of text that is already in the file: send `old_string` as that text, copied from the file, with `new_string` as what should stand in its place.
