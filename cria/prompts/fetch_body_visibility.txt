# the actual tool result out of the window the coder receives. Measured (Rust P20,

# claims, 1,045 with no call to that URL anywhere in the body the coder actually received. The coder
# then recalled nonexistent APIs from memory instead of reading — the block it was told to trust said
# reading was unnecessary, the transcript already had it.
#
# The exact-repeat fetch gate is already visibility-aware (webfetch.set_visible / _FETCH_SEEN): it
# refuses a repeat ONLY while the identical result is still in the conversation, and allows it again
# once compaction elides that result. This file's `body_absent` line is that SAME visibility fact,
# said instead of the false one — never new advice, and never a re-fetch instruction beyond the
# plain, checkable fact that a re-fetch is not blocked.
#
# `fetched_facts_sections.txt` (`body_inline` / `body_at`) is unmodified: a live comparable battery
# is running and cria re-reads prompts/*.txt on every call, so an EXISTING prompt file used by that

# `loop._format_fetches`.
