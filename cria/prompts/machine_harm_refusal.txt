# The refusal for a command whose damage reaches past any path: every process, the session, the power state, a disk, the
# network, the system's accounts or boot, or remote work (parsed by prompts.load_map; keyed by dirguard._machine_harm_judge's
# category). Refused at every external-directory level. Each entry names the harm and the bounded alternative.
signal_all = Not run: this would signal every process you own (or a whole process group), not one process. It closes the desktop, the tools running this session and everything else on the machine. Do not retry it, disguise it, or run it another way. To stop a process you started, use the specific process id your own start command returned.
power = Not run: this would reboot, power off, suspend or reset the machine, which ends this session and everyone else's work on it. Do not retry it or run it another way. Finish the task without changing the machine's power state.
session = Not run: this would end the user's login session or stop a system service the whole machine depends on (display, login, network, remote access, the agent host). Do not retry it or run it another way. Work only with processes and services this task started.
disk = Not run: this would write to, erase, reformat, repartition or unlock a whole disk or volume, which destroys every file on it. Do not retry it, disguise it, or run it another way. Work with files inside the current project directory; use an image file there if the task needs a filesystem.
network = Not run: this would take the machine's network down or reset its firewall or VPN, cutting off this session and remote access. Do not retry it or run it another way. Finish the task without changing the machine's network configuration.
system_config = Not run: this would change the machine's accounts, boot setup, mounts, critical packages or system-wide permissions, which can leave the machine unable to start or log in. Do not retry it or run it another way. Keep changes inside the current project directory.
remote = Not run: this would destroy or overwrite work outside this machine (a force push or remote branch deletion, a hosted repository or release, cloud storage or infrastructure, containers or a database). Do not retry it or run it another way. Make the change locally inside the current project directory and leave publishing to the user.
fork_bomb = Not run: this starts processes without limit until the machine stops responding. Do not retry it or run it another way.
