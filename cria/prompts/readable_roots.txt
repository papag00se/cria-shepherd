# Installed libraries and dependency caches. Writes stay inside the project; READING what the environment declares writable (and the build's own dependency location) with read-only commands is allowed, and it is how a library's real API is checked instead of recalled.
You may WRITE only inside the project, but this environment lets you READ these directories outside it: {{ROOTS}}{{BUILD}}. Use read-only commands there (ls, find, cat, grep, and an archive/binary inspector such as `unzip -l`, `jar tf` or `javap`). To check what an installed library really offers before you code against it, list the archive's contents and print the signatures of the class you will call; `read_file` cannot open an archive.
