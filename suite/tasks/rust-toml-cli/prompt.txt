Create a Rust command-line tool in this directory with Cargo.

Read a TOML file and print only the value at a dotted key path. 
> Example: `cargo run --quiet -- config.toml server.port` prints `8080`. 

Use a published crates.io TOML parser; do not write your own parser. If the file is missing or the key path does not exist, print an error to `stderr` and exit non-zero. Add unit tests for nested key lookup covering an integer, a string, and a missing key. Add a README explaining how to build, use, and test the tool.
