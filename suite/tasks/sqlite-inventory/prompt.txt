Build a small inventory tracker in Python backed by SQLite (standard library only). It must be a CLI named inventory.py supporting exactly these commands: `python3 inventory.py add <name> <quantity> <unit_price>` to add or restock an item (restocking the same name accumulates quantity), `python3 inventory.py list` to print every item with its quantity and unit price, and `python3 inventory.py value` to print the total value of the inventory (sum of quantity times unit price) as a number. The database file must be inventory.db in the working directory, created automatically with a sensible schema on first use. Write unit tests covering add, restock accumulation, and the value calculation. Add a README that explains setup, each command, and how to run the tests.
