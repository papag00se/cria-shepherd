# 2. Connect thoughts to context

Map the thought list to the context the coder received.

Work through the list in one pass. Search for relevant passages and read enough around each match to understand it.

For each thought, explain its connection to the context and cite the passage. Several thoughts may share one passage.

Distinguish:
- A connection explicitly stated in the reasoning.
- A plausible connection you infer.
- A connection you haven’t found.

You’re explaining how the thinking developed—not grading the work. Context that motivates an idea does not necessarily prove the idea correct.
