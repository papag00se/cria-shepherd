`writeproxy._read_command` only used `end_line` when a positive start was also present. Thus an omitted start fell into the whole-file path. On a small file this returned an unrequested tail; on a large file it refused an otherwise admissible prefix. The synthetic tool requires only `path` and advertises optional inclusive line bounds.
