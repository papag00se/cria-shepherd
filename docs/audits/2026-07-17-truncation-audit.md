# Truncation audit — every place cria cuts content (2026-07-17)

Principle (operator): **any truncation of content a model call reads is a lie the model can't detect** — it decides on falsified input. The only defensible cuts are (a) no model ever reads them, (b) a finite context window forces *lossless-summary* compression, or (c) a hard safety bound on a runaway.


**115 sites.** By what reads the cut content: `model-decision` 81 · `context-window-fit` 11 · `human-display` 11 · `internal` 12.


## TIER 1 — a model reads a TRUNCATED INPUT (the footgun: decide on a lie)
